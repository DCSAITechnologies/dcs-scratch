Generated by `scripts/remaining-gaps.py` from the synced catalogue: 809 published connectors.

- **411** connectors are complete for every field below.
- **397** still miss at least one field; **78** of those miss a P1 field (logo, site, portal, API reference or auth method).
- Egnyte is a separate lane and is not in these lists.

| Field | Priority | Missing | Where it comes from |
|---|---|---:|---|
| logo | P1 | 35 | press/brand kit, or the SVG in the provider's website header (square mark) |
| site | P1 | 39 | the provider's own homepage (HTTP 200 in a browser) |
| portal | P1 | 24 | developer portal / docs home, linked from the homepage footer or nav |
| api | P1 | 29 | API reference page (often /reference, /api, or a Postman/Stoplight page the portal links to) |
| auth | P1 | 8 | authentication page of the API docs |
| caps | P2 | 42 | API reference: 5-25 main operations, method + path as documented |
| reqs | P2 | 31 | getting-started / authentication page: account, plan, key or OAuth app needed |
| authDocs | P2 | 37 | authentication / API keys / OAuth page |

| whDocs | P3 | 0 | webhooks page (only when the provider documents webhooks) |
| statusUrl | P3 | 258 | status page (often status.<domain>); many providers have none, so notFound is a valid answer |

P1 is what a visitor sees first; do it before anything else. P3 fields legitimately do not exist for many providers: `notFound` is a valid, final answer for them.
